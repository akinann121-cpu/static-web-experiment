实验简介

本实验学习 HTML 页面结构、HTML 常用标记、 表格布局以及 CSS 样式表的基本使用方法。

知识结构

序号 知识内容 学习重点
1 HTML 基本结构 html、head、body、title
2 HTML 标记 标题、段落、超链接、图片
3 表格 table、tr、th、td
4 CSS 基础 颜色、字体、边距、布局

实验安排

  1. 建立 HTML 基本结构
  2. 添加标题、段落和超链接
  3. 制作实验内容表格
  4. 建立外部 CSS 样式表
  5. 在浏览器中检查网页效果
  6. 发布到 GitHub Pages
